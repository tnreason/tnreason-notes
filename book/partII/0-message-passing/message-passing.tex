\chapter{Message Passing Schemes}\label{cha:messagePassing}

\abstract{
    Message Passing schemes are effective ways to evaluate contractions.
    We first introduce based on semirings a more generic definitions of tensor network contraction.
    We then show that any such contraction can be splitted based on hypergraph cuts, which enables message-passing schemes to efficiently perform contractions.
    In the special cases of Boolean and basis encoding tensor networks, we further show even more efficient algorithms.
}
